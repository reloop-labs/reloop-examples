# Reloop SMTP - Nodemailer (Node.js) Example

Send emails using Reloop SMTP relay with Nodemailer in Node.js.

## Setup & Usage

1. Copy `.env.example` to `.env` and set your Reloop API key:
   ```bash
   cp .env.example .env
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the script:
   ```bash
   npm start
   ```
