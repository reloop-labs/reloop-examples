# Reloop Code Examples

Collection of official code examples and starter applications demonstrating how to integrate Reloop into your applications using SDKs or standard SMTP.

## SDK Examples

- [`node-express`](./node-express) - Node.js Express integration with `@reloop/node`
- [`python-fastapi`](./python-fastapi) - Python FastAPI integration with `reloop`
- [`go-app`](./go-app) - Go web server integration with `reloop-go`
- [`php-app`](./php-app) - PHP integration with `reloop-php`
- [`ruby-app`](./ruby-app) - Ruby application with `reloop-ruby`
- [`rust-app`](./rust-app) - Rust application with `reloop-rust`
- [`java-app`](./java-app) - Java Spring Boot application with `reloop-java`
- [`dotnet-app`](./dotnet-app) - .NET Web API application with `reloop-dotnet`
- [`elixir-app`](./elixir-app) - Elixir application with `reloop-elixir`

## SMTP Relay Examples

- [`smtp-nodemailer`](./smtp-nodemailer) - Node.js SMTP sending via `Nodemailer`
- [`smtp-python`](./smtp-python) - Python SMTP sending via built-in `smtplib`
- [`smtp-go`](./smtp-go) - Go SMTP sending via built-in `net/smtp`
- [`smtp-php`](./smtp-php) - PHP SMTP sending via `PHPMailer`
- [`smtp-ruby`](./smtp-ruby) - Ruby SMTP sending via built-in `net/smtp`
- [`smtp-rust`](./smtp-rust) - Rust SMTP sending via `Lettre`
