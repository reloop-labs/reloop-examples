# Reloop SMTP - PHPMailer (PHP) Example

Send emails using Reloop SMTP relay with PHPMailer in PHP.

## Setup & Usage

1. Copy `.env.example` to `.env` and set your Reloop API key:
   ```bash
   cp .env.example .env
   ```

2. Install dependencies:
   ```bash
   composer install
   ```

3. Run the script:
   ```bash
   php index.php
   ```
