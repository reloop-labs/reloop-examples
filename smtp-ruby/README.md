# Reloop SMTP - Ruby (`net/smtp`) Example

Send emails using Reloop SMTP relay with Ruby standard `net/smtp` library.

## Setup & Usage

1. Copy `.env.example` to `.env` and set your Reloop API key:
   ```bash
   cp .env.example .env
   ```

2. Install dependencies:
   ```bash
   bundle install
   ```

3. Run the script:
   ```bash
   ruby main.rb
   ```
